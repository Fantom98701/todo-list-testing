# TC-004. Добавление задачи длиной 200 символов

**Требование:** REQ-02  
**Тип:** Граничный  
**Приоритет:** Средний

## Предусловия

Приложение открыто, список задач пуст.

## Шаги

1. Ввести текст длиной ровно 200 символов
2. Нажать «Добавить»

## Тестовые данные

Строка из 200 символов:  
`aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa`

## Ожидаемый результат

Задача успешно добавлена. Текст отображается полностью.
