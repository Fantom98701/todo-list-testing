# TC-007. Редактирование текста задачи

**Требование:** REQ-04  
**Тип:** Позитивный  
**Приоритет:** Высокий

## Предусловия

В списке есть задача «Купить хлеб».

## Шаги

1. Дважды кликнуть по тексту задачи (или нажать кнопку «Редактировать»)
2. Изменить текст на «Купить молоко»
3. Нажать Enter или кнопку «Сохранить»

## Ожидаемый результат

Текст задачи изменился на «Купить молоко».
