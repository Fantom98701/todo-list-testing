# TC-005. Добавление задачи длиной 201 символ

**Требование:** REQ-02  
**Тип:** Граничный  
**Приоритет:** Средний

## Предусловия

Приложение открыто, список задач пуст.

## Шаги

1. Ввести текст длиной 201 символ
2. Нажать «Добавить»

## Тестовые данные

Строка из 201 символа (200 символов «a» + 1 символ «b»).

## Ожидаемый результат

Задача не добавляется **или** текст обрезается до 200 символов.  
Появляется сообщение об ошибке / ограничении длины (если реализовано).
