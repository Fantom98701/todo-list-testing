# TC-013. Счётчик активных задач

**Требование:** REQ-09  
**Тип:** UI  
**Приоритет:** Средний

## Предусловия

Список задач пуст. Счётчик показывает «0 items left» (или аналог).

## Шаги

1. Добавить 3 задачи
2. Отметить 1 задачу как выполненную

## Ожидаемый результат

Счётчик показывает «2 items left» (или «2 активных»).  
При удалении / добавлении / изменении статуса счётчик обновляется корректно.
