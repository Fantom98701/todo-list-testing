# TC-006. Отметка задачи как выполненной

**Требование:** REQ-03  
**Тип:** Позитивный  
**Приоритет:** Высокий

## Предусловия

В списке есть хотя бы одна активная задача (например, «Купить хлеб»).

## Шаги

1. Нажать на чекбокс (или кнопку отметки) рядом с задачей

## Ожидаемый результат

- Задача отмечена как выполненная
- Текст задачи перечёркнут (или визуально отличается)
- Счётчик активных задач уменьшился на 1
