# TC-008. Удаление задачи

**Требование:** REQ-05  
**Тип:** Позитивный  
**Приоритет:** Высокий

## Предусловия

В списке есть задача «Купить хлеб».

## Шаги

1. Нажать кнопку «Удалить» (крестик) рядом с задачей

## Ожидаемый результат

Задача удалена из списка.  
Счётчик активных задач обновился (если задача была активной).
