# TC-015. Отмена редактирования по Escape

**Требование:** REQ-04  
**Тип:** Негативный  
**Приоритет:** Низкий

## Предусловия

В списке есть задача «Купить хлеб».

## Шаги

1. Дважды кликнуть по тексту задачи (войти в режим редактирования)
2. Изменить текст на «Купить молоко»
3. Нажать клавишу Escape

## Ожидаемый результат

Редактирование отменено.  
Текст задачи остался «Купить хлеб» (изменения не сохранились).
