# Todo-List Testing

Репозиторий с тестовой документацией для приложения «Список задач» (Todo-List).

## Описание

Веб-приложение для управления личными задачами. Документация включает требования, тест-кейсы, тестовые пакеты, баг-репорты и отчёт о покрытии.

## Структура

| Папка / Файл | Описание |
|--------------|----------|
| `requirements.md` | Требования к приложению |
| `test-cases/` | Тест-кейсы (15 шт.) |
| `test-suites/` | Тестовые пакеты (5 шт.) |
| `test-run/` | Результаты прогона |
| `bug-reports/` | Баг-репорты |
| `coverage/` | Отчёт о покрытии требований |

## Тестовые пакеты

| Пакет | Цель | Количество ТК |
|-------|------|---------------|
| Smoke | Быстрая проверка работоспособности | 1 |
| Core Functions | Основные функции | 5 |
| Negative | Обработка ошибочных данных | 4 |
| Boundary | Граничные значения | 2 |
| UI & Filtering | Интерфейс и фильтрация | 5 |
