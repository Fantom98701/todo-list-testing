# TC-014. Адаптивность 320px

**Требование:** REQ-10  
**Тип:** UI  
**Приоритет:** Средний

## Предусловия

Приложение открыто в браузере.

## Шаги

1. Открыть инструменты разработчика (F12)
2. Включить режим эмуляции устройства
3. Установить ширину viewport = 320px
4. Проверить отображение интерфейса

## Ожидаемый результат

- Все элементы интерфейса видны и доступны
- Нет горизонтальной прокрутки
- Кнопки и поля ввода удобны для использования
- Текст не обрезается критично
