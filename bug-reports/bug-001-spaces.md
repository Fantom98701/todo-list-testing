
# BUG-001. Задача из пробелов добавляется в список

**Связанный тест-кейс:**   
**Приоритет:** Средний  
**Статус:** Open

## Шаги воспроизведения

1. Открыть приложение Todo-List
2. Ввести несколько пробелов в поле ввода задачи
3. Нажать «Добавить»

## Ожидаемый результат

Задача не добавляется. Список остаётся без изменений.

## Фактический результат

Задача с пустым (или состоящим из пробелов) текстом появляется в списке.

## Окружение

- Браузер: Chrome 120+
- ОС: Windows / macOS / Linux
